# LARP Studio — браузерная мастерская

**Открыть мастерскую: https://mgoutside16-spec.github.io/larp/**

Основной вариант — сайт по постоянной ссылке. Пользователю нужен только браузер.
Python, Node.js, установщик и локальный сервер на его компьютере не нужны.

## Работа с играми

1. Создайте игровой проект и при необходимости добавьте локации.
2. Создавайте записи, добавляйте текст, фото, аудио и видео. Пятизначные коды
   выдаются автоматически и не меняются при редактировании и создании сборок.
3. Меняйте порядок блоков и проверяйте результат в предпросмотре игрока.
4. Скачивайте карточки PDF A4 и список кодов Excel.
5. Создавайте `.rpgpack` для резервного копирования и переноса. Импорт открывает
   независимый проект, не затирая существующий.

Игры и медиа сохраняются в **IndexedDB браузера**, отдельно от JS/CSS приложения.
После публикации новых функций достаточно обновить страницу. Игра остаётся в том
же браузере по тому же адресу. Очищение данных сайта и приватный режим могут удалить
локальные данные: сохраняйте резервные `.rpgpack`. Между устройствами нет скрытой
автосинхронизации — используйте экспорт и импорт. Игровой контент не загружается
на сервер. Пока страница открыта, материалы можно редактировать без сети;
холодный запуск сайта без сети в этой версии не гарантируется.

## Обновления через Codex

Исходники находятся в `web/`. Публикация из ветки `main` выполняется workflow
`.github/workflows/pages.yml`: Node tests, сборка, браузерные сценарии и GitHub Pages.
Перед публикацией проверяется сохранение существующих игр после замены JS-кода.
Нельзя менять имя базы `larp-studio`, очищать IndexedDB при обновлении или менять
ключи существующих проектов без сохраняющей данные миграции.

Первое включение Pages требует соответствующего права GitHub. Если оно закрыто
для подключённой интеграции, владелец репозитория включает Settings → Pages →
Source: GitHub Actions один раз. Это действие в GitHub, не установка программы.

## Для разработки в облачной среде

Это команды для Codex/разработчика; пользователь сайта их не выполняет.

```bash
cd web
npm ci
npm test
npm run build
npm run dev -- --port 5173
```

Нужен Node.js 22+ (в текущей среде 24). Playwright-проверки выполняются против
собранного `web/dist` на внутреннем тестовом HTTP-сервере:

```bash
python3 -m http.server 5173 --bind 127.0.0.1 --directory web/dist
# В другой сессии:
python3 web/tests/browser_check.py
python3 web/tests/regression_check.py
```

Используется системный Chromium или браузер, установленный Playwright. В CI все
инструменты устанавливаются автоматически. Локальные адреса не являются ссылкой
на опубликованный сайт.

## Форматы и ограничения

Сохраняется совместимость `.rpgpack` v1 с Python-мастерской. Браузерная версия
отклоняет архивы больше 1 ГиБ после распаковки, файлы больше 512 МиБ, manifest
больше 16 МиБ и ZIP64. Экспорт проверяет эти же ограничения до фиксации версии.
Числа должны точно представляться в JavaScript (safe integer). Объём локальных
игр дополнительно ограничивается квотой браузера. Эти ограничения указаны для
надёжной обработки больших медиа в памяти, а не для ограничения числа блоков.

Поддержка аудио/видео зависит от браузерных кодеков. Для обмена рекомендуются
PNG/JPEG, MP3/WAV и MP4 H.264/AAC. Текст допускает базовое форматирование;
внешние ресурсы и активный HTML удаляются при показе.
