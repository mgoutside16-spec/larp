# Проверки LARP Studio

## Версия 0.3 — аккаунты, совместные проекты и изображения карточек

- 26/26 Node tests прошли: в том числе настоящая IndexedDB, изоляция предложения
  записи от общего кеша, CAS-повторы, конфликт одной записи, безопасное удаление
  файлов после серверного успеха, группы, шаблоны и PNG pHYs 300 dpi.
- 158 проверок на настоящем PostgreSQL 17 прошли: RLS администратора/мастера,
  совместные проекты, приглашения, запрет повышения роли, подтверждённая почта,
  постоянство кодов, история, версии, приватные файлы и удаление.
- Проверен повторяемый переход от первой установленной схемы через account-update.sql.
- Браузер: 10 исходных приёмочных сценариев и 2 регрессии сохранены с реальным
  SDK авторизации и изолированным HTTP/WebSocket протоколом Supabase для CI.
  Загрузки File/Blob проходят настоящий loopback HTTP и проверку SHA256: перехват
  Chromium postData пропускает байты файлов из FormData.
- 8 сценариев личного кабинета проверяют двух мастеров/компьютера, общие и личные
  проекты, параллельные записи/конфликт одной записи, шаблон на другом устройстве,
  администратора, профиль, выход и задержанное открытие сеанса после выхода.
- 5 регрессий ревью проверяют ZIP при фоновой синхронизации, полный код при большом
  шрифте, имя регистрации, сообщения групп и выбор проекта после удаления коллегой.
- Реальная форма входа с рабочим публичным подключением отображается; рабочий
  Supabase отклоняет анонимное чтение проектов (HTTP 401, PostgreSQL 42501).
- Действительное создание пользовательского аккаунта и подтверждение почты выполняет
  владелец. Тестовые браузерные сценарии не отправляют настоящих писем и не доказывают
  SMTP-доставку. Права базы проверены отдельно настоящим PostgreSQL.
- Production npm audit: 0 уязвимостей. Независимое ревью завершено, найденные ошибки
  воспроизведены до исправления и включены в регрессии.

Облачные проекты требуют сети. Квоты зависят от тарифа Supabase; PNG-выгрузка
ограничена 500 карточками/256 МиБ памяти на один архив. В пользовательской базе
скрипты выполнены по подтверждению владельца.

Публикация 0.3: **run 40202136444**, policies/build/deploy — success.

## Перед передачей мастерской пользователям Windows

1. Запустить workflow Windows или установить зависимости и запустить весь pytest.
2. Собрать `python -m PyInstaller --noconfirm LARPStudio.spec`.
3. На чистой Windows проверить запуск всей папки dist без установленного Python.
4. В папке с кириллицей создать проект, добавить фото/MP3/MP4, изменить порядок,
   сохранить и перезапустить. Проверить текст/картинку/звук/видео внутри программы.
5. Сформировать XLSX/PDF/пакет, импортировать на другой компьютер, проверить байты
   медиа, кириллицу, постоянство кодов и печать A4.

Для воспроизведения в текущей среде:

```bash
cd /workspace/larp
/workspace/.venvs/larp-studio/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen LARP_STUDIO_CONFIG_DIR=/workspace/.larp-studio \
  /workspace/.venvs/larp-studio/bin/python -m larp_studio --smoke-test
```
