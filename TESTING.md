# Проверки LARP Studio

## Браузерная версия 0.2 — основной продукт

Среда: Chromium headless, Node 24.19.0, TypeScript 5.9.3, Vite 7.3.7.

- **12/12 Node tests прошли**: IndexedDB, неизменные/уникальные коды, резерв
  удалённых, восстановление после закрытия, копирование медиа, атомарный отказ,
  конфликт вкладок, независимая копия, пакеты и ограничения размера.
- **10/10 браузерных приёмочных сценариев прошли**: реальное создание/сохранение,
  мультимедиа и порядок, перезагрузка, поиск/фильтр, замена JS-кода с сохранением
  существующей игры, XLSX/PDF/пакет, импорт в новый браузер, узкий экран и отсутствие
  необработанных ошибок JavaScript.
- **2/2 браузерные регрессии прошли** после независимого ревью: Enter сохраняет
  абзацы; сохранение ожидает копирование медиа и сохраняет текст, введённый в это время.
- Изменение файлов приложения реально проверялось заменой URL JS-сборки и
  перезагрузкой страницы: версия интерфейса изменилась, игра, код и название остались.
- Пакет браузера проверен и импортирован Python-мастерской; браузерный XLSX
  прочитан openpyxl, PDF — pypdf. Пятизначный код присутствует, спойлерное имя скрыто.
- `npm run build` завершился успешно. Проверка production-зависимостей: 0 уязвимостей.

Сайт ещё должен пройти фактическую публикацию и проверку HTTPS-адреса; локальные
проверки сами по себе не доказывают размещение. Включение Pages через API текущей
интеграции вернуло 403; возможность публикации workflow проверяется отдельно.
Firefox/Safari, физический вывод звука и очень большие медиатеки не проверялись.

## Desktop-версия 0.1 — сохранённая дополнительная реализация

Дата: 25.10.2026. Среда: Linux x86_64, Python 3.12.14, Qt/PySide6 6.10.0,
SQLAlchemy 2.0.44. Итоги обновляются по фактическим запускам.

## Подтверждено

- Установка dev-зависимостей в отдельную виртуальную среду.
- Editable-установка приложения; `pip check`: No broken requirements found.
- Итоговый полный запуск: **60 passed**, 0 failed, 0 skipped.
- `python -m larp_studio --smoke-test` с Qt offscreen завершился с кодом 0.
- Снимки реальных окон мастерской и редактора просмотрены вручную.
- Проверены создание и повторное открытие, уникальные постоянные коды,
  резерв удалённых, исчерпание диапазона, локации, порядок блоков,
  копирование медиа и кириллица в Linux-путях.
- Ошибка SQLite во время изменения блоков откатывает название и прежние блоки.
- XLSX открывается openpyxl, PDF читается pypdf, кириллица извлекается корректно;
  PDF по умолчанию скрывает название и локацию; данные Excel не становятся формулами.
- Пакеты проходят полный экспорт/импорт с сохранением UUID, кодов, порядка блоков
  и байтов медиа. Повреждённые checksum, ZIP и обход пути отклоняются.
- Qt: редактор/отмена, перестановка блоков, фильтр/поиск, предпросмотр текста/фото.
- Сквозной сценарий с нажатием кнопок: создание записи, копирование кода,
  экспорт XLSX/PDF/пакета и повторное открытие проекта.
- Qt Multimedia загрузил скопированный WAV и определил длительность 1000 мс.
- После независимого ревью воспроизведены и исправлены ошибки commit экспорта,
  Windows-коллизий имён, подмены содержимого повторного медиа и переполнения INTEGER.
  Дополнительно проверены гонка создания папки и выход через симлинк.
- `PyInstaller --noconfirm LARPStudio.spec` создал **Linux**, не Windows,
  дистрибутив (~251 МиБ). Его бинарный файл запущен с `--smoke-test`, в том числе
  с существующим проектом: код 0. PDF-шрифт и лицензия присутствуют в сборке.
- Повторный запуск сохранённого install_script завершился успешно; `pip check` чист.

Сборщик сообщил об отсутствующих необязательных драйверах pysqlite2/MySQLdb/
psycopg2 и libtiff.so.5 для Qt TIFF-плагина. Используется стандартный sqlite3;
MySQL/PostgreSQL и TIFF не входят в поддерживаемый сценарий этой версии.

## Границы проверки

- Windows EXE ещё не собран и не запускался в этой Linux-сессии.
- Windows CI подготовлен, но не выполнялся; результаты GitHub Actions отсутствуют.
- Пути Windows с буквой диска, поведение антивируса, масштабирование DPI,
  аудио/видеокодеки и физический звук требуют проверки на целевой Windows-машине.
- Qt offscreen проверяет виджеты и обработчики, а не удобство мыши на Windows.
- Тест загрузки WAV не доказывает вывод звука на физическое устройство.
- Мобильное приложение и сервер не реализованы и не тестировались.
- Не проведены нагрузочные испытания медиатек на гигабайты и всех 90 000 активных записей.

## Перед передачей мастерской пользователям Windows

1. Запустить workflow Windows или установить зависимости и запустить весь pytest.
2. Собрать `python -m PyInstaller --noconfirm LARPStudio.spec`.
3. На чистой Windows проверить запуск всей папки dist без установленного Python.
4. В папке с кириллицей создать проект, добавить фото/MP3/MP4, изменить порядок,
   сохранить и перезапустить. Проверить текст/картинку/звук/видео внутри программы.
5. Сформировать XLSX/PDF/пакет, импортировать на другой компьютер, проверить байты
   медиа, кириллицу, постоянство кодов и печать A4.

Для воспроизведения в текущей среде:

```bash
cd /workspace/larp
/workspace/.venvs/larp-studio/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen LARP_STUDIO_CONFIG_DIR=/workspace/.larp-studio \
  /workspace/.venvs/larp-studio/bin/python -m larp_studio --smoke-test
```
