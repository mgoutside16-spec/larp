## Перед передачей мастерской пользователям Windows

1. Запустить workflow Windows или установить зависимости и запустить весь pytest.
2. Собрать `python -m PyInstaller --noconfirm LARPStudio.spec`.
3. На чистой Windows проверить запуск всей папки dist без установленного Python.
4. В папке с кириллицей создать проект, добавить фото/MP3/MP4, изменить порядок,
   сохранить и перезапустить. Проверить текст/картинку/звук/видео внутри программы.
5. Сформировать XLSX/PDF/пакет, импортировать на другой компьютер, проверить байты
   медиа, кириллицу, постоянство кодов и печать A4.

Для воспроизведения в текущей среде:

```bash
cd /workspace/larp
/workspace/.venvs/larp-studio/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen LARP_STUDIO_CONFIG_DIR=/workspace/.larp-studio \
  /workspace/.venvs/larp-studio/bin/python -m larp_studio --smoke-test
```
