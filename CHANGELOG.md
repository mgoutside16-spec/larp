# История изменений

## 0.3.0 — 25.10.2026

- Добавлены вход/регистрация/восстановление пароля и личный кабинет с Supabase.
- Добавлены роли администратора и мастера, совместные проекты, участники,
  отложенные приглашения по почте и их отзыв. Доступ защищён серверными RLS.
- Подтверждённая почта первого владельца получает административные права через
  одноразовое разрешение; публичная регистрация не повышает роль.
- Параллельные правки разных записей объединяются; одна запись защищена revision.
- Локации переименованы в группы, прежние связи и коды сохранены.
- Добавлены название «Без правил», эмблема и пример «Сновидение» из PDF.
- Добавлена печать на изображении: drag кода, шрифт/размер/цвет, шаблоны групп,
  ZIP PNG с исходным разрешением и 300 dpi, сохранение шаблонов в проекте.
- Исправлены гонка общего кеша, отмена ZIP фоновой синхронизацией, обрезка больших
  цифр, потеря имени при регистрации, сообщения групп и выбор удалённого проекта.
- Удаление проекта освобождает файлы после успешной проверки версии.

## 0.2.0 — 25.10.2026

- По уточнению пользователя основная поставка изменена на браузерный сайт без установки.
- Добавлена веб-мастерская: проекты, записи, постоянные коды, локации, упорядоченные
  мультимедийные блоки, форматирование, предпросмотр, поиск и фильтры.
- Игры и медиа хранятся в IndexedDB независимо от файлов программы; обновления
  интерфейса не очищают хранилище. Изменения из другой вкладки не затираются молча.
- Добавлены браузерные PDF/Excel и совместимые `.rpgpack`, перенос между устройствами.
- Добавлены автоматическая сборка/публикация GitHub Pages и тест замены JS-кода
  с сохранением существующего проекта.
- По независимому ревью исправлены переносы строк Enter, сохранение во время
  обработки медиа и совпадение лимитов экспорта с импортом.
- Python desktop-реализация сохранена как дополнительная; её CI запускается вручную.

## 0.1.0 — 25.10.2026

- Создан LARP Studio на Python/PySide6 с русским интерфейсом.
- Добавлены независимые SQLite-проекты, повторное открытие, копирование и настройки.
- Реализованы записи, постоянные автоматические пятизначные коды и резерв удалённых.
- Добавлены локации, таблица, поиск, фильтры, сортировка и копирование кода.
- Добавлены упорядоченные блоки текста, изображений, аудио и видео, копирование медиа,
  перетаскивание файлов, базовое форматирование и внутренний предпросмотр.
- Добавлены Excel и PDF A4 с настройками скрытия сюжетных названий.
- Добавлены версии `.rpgpack`, SHA-256, валидация и импорт в новую папку.
- Добавлены автоматические тесты и конфигурация Windows-сборки PyInstaller/CI.
- Исправлен начальный фильтр: при открытии отображаются все локации.
- Добавлены регрессии по результатам независимого ревью: восстановление экспорта
  при ошибке commit, безопасные Windows-имена в ZIP, проверка повторного медиа,
  ограничение числовых полей, защита чужих каталогов и симлинков.

Мобильный клиент, сервер и выпуск проверенного Windows EXE — следующие этапы.
