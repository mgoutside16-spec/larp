# LARP Studio Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Реальная мастерская с сохранением, материалами, кодами и экспортом.
**Architecture:** Независимые сервисы хранения и экспорта; Qt обращается к ним.
**Tech Stack:** Python, PySide6, SQLAlchemy, openpyxl, ReportLab, pytest.
**Spec:** SPEC.md; docs/superpowers/specs/2026-10-25-workshop-design.md.

## Global Constraints

- Коды ровно 5 цифр, 10000–99999, только автоматически, не меняются.
- Только локальный контент, русский интерфейс, никакого обязательного сервера.
- Проект независим, медиа копируются, пакеты без абсолютных путей.
- Windows — целевая платформа; Linux-проверки не заменяют Windows-проверки.

## Review Focus

- Отказ диска при сохранении не должен терять старую запись/экспорт.
- Повреждённый или опасный ZIP не должен менять рабочий проект.
- Дубликаты имен медиа не должны затирать разные файлы.
- Пустой проект и удалённая локация должны корректно отображаться.
- Отмена редактора не должна менять запись и её код.
