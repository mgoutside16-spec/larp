# LARP Studio: Windows-мастерская

Основное ТЗ: `SPEC.md`. Пользователь прямо поручил начать реализацию.
Первая поставка охватывает этапы 1 и 2; Flutter и сервер не разрабатываются.

## Архитектура

Python 3.11+, PySide6 Widgets, SQLite через SQLAlchemy Core, openpyxl,
ReportLab, pytest/pytest-qt, PyInstaller. Это стек из ТЗ; выбор Core вместо ORM
сделан разработчиком для небольшого переносимого локального проекта.
Альтернативы: веб-интерфейс потребовал бы локального сервера и другого
упаковывания; Flutter Desktop усложнил бы первую реализацию на Python.
Сохраняем рекомендованный стек без дополнительных сервисов.

Папка игрового проекта содержит `project.sqlite3` и `media/`. База хранит
метаданные игры, локации, записи, упорядоченные блоки, реестр когда-либо
выданных кодов и версии сборок. Идентификатор проекта — UUID. Пять цифр
10000–99999 выдаются через `secrets`; уникальность обеспечивается базой.
Изменение и удаление записи не освобождают код. При исчерпании диапазона
показывается ошибка. Все изменения записи выполняются транзакционно.

Медиа копируются по SHA-256, пути относительные, оригиналы можно удалить.
Удаление записи не удаляет общие медиа. Копия проекта получает новый UUID.
Отсутствующие файлы не допускаются к экспорту. Недоверенные архивы проверяются
до создания целевой папки: имена, размеры, дубликаты, схема, коды, ссылки,
контрольные суммы. Обновление существующего проекта импортом в первой версии
не выполняется: импорт создаёт новый независимый каталог, не рискуя старым.

`.rpgpack` — ZIP с UTF-8 `manifest.json`, версией формата 1, UUID игры,
монотонной версией сборки, записями/локациями, `media/` и SHA-256. Версия
записывается в историю только после успешного экспорта. Атомарная запись
выходного файла и импорт через временную соседнюю папку. Код не меняется.
Будущему мобильному клиенту достаточно читать manifest, SQLite не обязателен.

## Интерфейс

Русский интерфейс рабочего инструмента: слева навигация и проект, в центре
таблица записей с поиском и фильтром локации. Редактор в отдельном диалоге:
название, неизменяемый код, локация, блоки, форматирование и предпросмотр.
Медиа проигрываются через Qt Multimedia внутри окна. Файлы можно перетащить.

Цвета: бумажный белый #FAFBFD, чернильный #253448, синий #315EA8,
серый #E1E7EF, красный ошибок #B33F45. Шрифт Segoe UI на Windows,
системный sans-serif на Linux; заголовки 22 px, текст 14 px. Акцент на
пятизначном коде и порядке материалов, без декоративных карточек.
Экспорт PDF по умолчанию скрывает названия и локации от игрока.

## Проверки и границы

Тесты покрывают сценарии раздела 8: сохранение, коды, блоки, медиа, пакеты,
кириллицу, транзакции, PDF/XLSX. Qt проверяется с offscreen-платформой в Linux.
Linux не подтверждает сборку/запуск EXE, Windows-пути с буквой диска и
системные мультимедийные кодеки Windows. Для этого отдельный CI Windows.
В первой версии нет сервера, мобильного клиента, подписания iOS и обновления
установленной мобильной игры. Ручное тестирование звука/видео на Windows
остаётся обязательным перед выдачей конечным пользователям.
