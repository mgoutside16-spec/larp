# LARP Studio в браузере — первоначальная версия 0.2

> Историческое решение. Версия 0.3 добавляет обязательные аккаунты, Supabase и
> совместную работу: актуальная архитектура в [ACCOUNT-WORKSHOP-DESIGN.md](ACCOUNT-WORKSHOP-DESIGN.md).
> Описанное ниже локальное хранилище сохраняется для переноса прежних проектов.

Пользователь выбрал браузер по постоянной ссылке, без установки, с сохранением
игр при изменениях приложения через Codex. Windows EXE больше не основной способ
поставки. Существующая Python-мастерская сохраняется; веб-версия использует тот же
контракт `.rpgpack`. Мобильный игрок и сервер обновлений по-прежнему отложены.

Выбран статический сайт: TypeScript/Vite, IndexedDB (idb), fflate, ExcelJS,
jsPDF. Хостинг — GitHub Pages по возможности доступа. У пользователя нет Python,
Node и локального сервера. Альтернатива серверу Python позволила бы повторно
использовать исходники напрямую, но потребовала бы серверной базы, авторизации
и хостинга. Для индивидуальной мастерской браузерное хранилище проще и сохраняет
игры при обычном обновлении сайта. Код сайта и IndexedDB независимы.

IndexedDB `larp-studio`, схема v1: games с метаданными/записями/реестром кодов,
media с Blob-объектами по [gameId,path], preferences. Обновления JS/CSS не меняют
имя базы и не очищают данные. Миграции только явно версионированные и сохраняющие
данные. Проекты не синхронизируются между браузерами автоматически: для переноса
служит `.rpgpack`. Интерфейс ясно показывает локальное хранение и резервную копию.

Операции записи в IndexedDB транзакционные; новый контент и метаданные фиксируются
вместе. Окно редактора держит изменения отдельно до сохранения. Новый код выдаётся
через crypto.getRandomValues, 10000–99999, с резервом удалённых кодов. Существующий
код неизменяем. Импорт проверяет все данные до добавления нового проекта.
Приложение не передаёт игровые материалы на сервер. Медиа проигрываются из Blob
внутри страницы. HTML текста очищается до разрешённого форматирования.

Визуальная система: тёмно-синий #193348 для навигации, рабочий белый #FFFFFF,
серо-голубой #F1F4F8, чернила #263849, золотистый #E7B36D для небольшого акцента,
синий #2D649C для действий. Шрифты системные, без внешней загрузки. Постоянная
левая навигация, таблица материалов, отдельный выдвижной редактор и предпросмотр
игрока. На узком экране навигация сворачивается, действия остаются доступны.

Проверки: Node tests для кодов, IndexedDB и миграции данных; Playwright для
создания/редактирования/перезагрузки, медиа, поиска, экспорта/импорта и сохранения
данных при замене версии JS. Никаких пользовательских ссылок на localhost.
Публикация считается выполненной только после проверки публичного HTTPS-адреса.
