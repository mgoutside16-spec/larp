# «Без правил» — приложение игрока

Установщик Android: https://github.com/mgoutside16-spec/larp/releases/latest/download/LARP-Player.apk

Требуется Android 7 или новее. Универсальный APK подходит ARM32, ARM64 и x86_64.
Для большинства современных телефонов есть уменьшенный [APK ARM64](https://github.com/mgoutside16-spec/larp/releases/latest/download/LARP-Player-arm64.apk).
Для старых телефонов с 32-битным ARM — [APK ARM32](https://github.com/mgoutside16-spec/larp/releases/latest/download/LARP-Player-arm32.apk),
для устройств с Intel — [APK x86_64](https://github.com/mgoutside16-spec/larp/releases/latest/download/LARP-Player-x86_64.apk).
Если архитектура неизвестна, используйте универсальный установщик по первой ссылке.
Никакие Python, Flutter или инструменты разработки игроку не нужны.

## Начало игры

1. Скачайте APK на телефон и откройте его. При запросе Android разрешите
   установку из браузера/файлового менеджера, которым открыли файл.
2. Запустите «Без правил».
3. Дождитесь автоматической загрузки проектов при подключении к интернету.
4. Выберите проект, в котором участвуете, и напишите имя персонажа.
5. Введите пять цифр с игровой карточки и нажмите «Открыть материал».

Текст, изображения, аудио и видео после загрузки открываются без интернета.
Материалы идут в порядке мастера, картинки можно увеличить. Имя можно изменить
на экране кода; при отсутствии сети оно отправится мастеру позже. Вкладки «История» нет.
После трёх неверных кодов подряд ввод блокируется на 30 минут; перезапуск,
переименование персонажа и обновление не снимают блокировку. Неполный ввод
не расходует попытку. Состояние раздельное для разных игр.

## Обновления

**Онлайн:** сохранения проекта/материала в мастерской достаточно. Приложение
проверяет все проекты при запуске, возврате и каждые 20 секунд в открытом окне.
Загрузка и установка автоматические; состояние/ошибка и повтор видны в списке.
При обрыве прежняя игра сохраняется. Вход/пароль игроку не нужен.

**Офлайн:** получите новый `.rpgpack`, откройте список игр и выберите «Импорт .rpgpack».
Нужна более новая версия той же игры. Прежние ссылки/публикации поддерживаются.

Обновления материалов не требуют нового APK. Изменения кода приложения выходят
новым APK с той же подписью: устанавливайте его **поверх прежнего приложения**,
без удаления приложения и данных. Для версии 0.5 администратор один раз выполняет
`backend/player-auto-sync.sql` после прежних SQL-миграций.

## Для разработчика

`../scripts/setup-mobile-toolchain.sh` устанавливает проверенные версии Linux SDK.
`source ../scripts/mobile-env.sh`, затем `flutter analyze` и `flutter test`.
SDK/кеши находятся в `/workspace`, телеметрия выключена, HOME не переопределяется.
Подписанная сборка: `LARP_SIGNING_PROPERTIES=/путь/к/приватным.properties
../scripts/build-player-apk.sh`. Ключ и пароли не входят в Git или публичный APK.
Сохраните исходный ключ: другой ключ не позволит обновить установленное приложение.
Скрипт создаёт универсальный APK и три уменьшенных APK по архитектурам в `../dist`,
проверяет подпись и записывает SHA256 для каждого файла. Все варианты одной версии
имеют одинаковый Android versionCode, поэтому при обновлении можно сменить вариант
APK на совместимый с телефоном. Это задаёт `force-version-code-ignoring-abi=true`
в `android/gradle.properties`; без него Flutter добавляет к versionCode номер архитектуры.

Flutter-команды выполняйте последовательно. Одновременный pub get/test/build
может перезаписать GeneratedPluginRegistrant и сломать release-компиляцию.
В CI выполняются анализ, тесты и Android debug-компиляция; распространяется
отдельный подписанный release APK. Для подписи CI потребовались бы repository
secrets, недоступные текущей GitHub-интеграции; локальная подпись работает.

PNG на некоторых Android отклоняется системным zlib. Приложение использует
резервный потоковый Dart-декодер, сохраняя прозрачность. Для просмотра изображения
ограничены 64 МиБ/40 мегапикселей, чтобы не переполнить память устройства. Локальная
копия PNG-декодера image4.12.0 с MIT-лицензией заменяет только inflater; версии
image/archive закреплены. Перед обновлением этих зависимостей проверяйте нативный
PNG, полупрозрачность и время жизни raw-буфера до первого кадра.

Нативная проверка: `integration_test/player_smoke_test.dart`; запускается против
Android с установленными SDK/adb. Без KVM используется медленный контейнерный
эмулятор из `../scripts/start-android-runtime.sh`. Временная тестовая игра не
заменяет реальные игровые данные. Генератор видео-фикстуры использует FFmpeg.

Ограничения: новое описание игры устанавливается целиком; известные файлы с проверенным SHA256 повторно не скачиваются.
Предыдущие каталоги пока сохраняются, в том числе ради истории удалённых записей;
автоматическая очистка неиспользуемых старых каталогов ещё не реализована.
Пакет ≤1 ГиБ распакованных данных, отдельное медиа ≤512 МиБ, manifest ≤16 МиБ;
серверный тариф может ограничивать размер загрузки сильнее (обычно 50 МиБ на Free).
Исходная структура iOS включена, подписанная iOS-сборка на Linux не проверялась.
