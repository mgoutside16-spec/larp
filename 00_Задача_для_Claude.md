# Задача для Claude

Помоги выбрать архитектуру LARP Studio для мастерской «Без правил».
Пока нужен анализ, а не немедленное переписывание системы.

Прочитай 00_Контекст_для_Claude.md, 00_Последние_требования.md и 00_Карта_базы.md.
Полное исходное ТЗ: 02_Originals/Исходное техническое задание.txt.
Реализованное состояние: 01_Source/SPEC.md, README.md, TESTING.md и сам код.
Старые планы могут быть устаревшими; последнее обсуждение архитектуры ещё не реализовано.

Пользователь не программист, предпочитает русский интерфейс и одно приложение Windows.
Игры проходят примерно раз в полгода; постоянная аренда нежелательна, приоритет бесплатному.
Нужны локальное хранение/редактирование, резервные копии и обновления программы без потери
данных. При сети — совместная работа мастеров с прежними правами и передача материалов
игрокам. Android уже существует, офлайн и .rpgpack сохранить. В будущем PWA для iPhone.
Ноутбук ездит на полигон, IP/сеть меняются. Игроки подключаются из разных мест через интернет;
установка VPN/сетевых утилит на телефоны нежелательна. Когда ноутбук выключен, новые файлы
с него получить нельзя; ранее загруженная игра должна работать.

Облако Supabase на бесплатном плане приостановилось; мастерская не могла войти.
Скриншот подтверждает паузу и сохранность данных, причина неактивности вероятна по
официальным правилам, но личное уведомление сервиса не изучено. Нельзя путать это
с потерей данных или доказанным дефектом программы.

Сравни: ноутбук с прямым доступом, бесплатный туннель, бесплатное хранилище/хостинг,
временный платный сервер только на период мероприятия, сохранение/замену Supabase.
Прошлый помощник предложил Tailscale Funnel, но проверки скорости/нагрузки не было.
Документация: https://tailscale.com/docs/features/tailscale-funnel
Тариф: https://tailscale.com/pricing — Personal для некоммерческого использования.
У Funnel заявлены ограничения пропускной способности, он пока обозначен beta.
Не считать этот вариант выбранным или гарантированно подходящим.

Для каждого подхода объясни стоимость, условия бесплатности, смену IP/CGNAT,
исходящую скорость, 40-МБ видео и одновременную загрузку, обязанности владельца,
необходимые установки и аккаунты, независимость локальных данных, аварии и бэкапы.
Разделяй обновления игрового контента и обновления самой программы.
Проверь действующие условия по официальным источникам; trial не считать бесплатным навсегда.
Число игроков, объём медиа, связь на полигоне, ограничения провайдера и коммерческий
статус неизвестны. Перечисли, что нужно выяснить. Предложи один подход и минимальную
проверку. Не обещай бесплатную надёжную круглосуточную раздачу без ограничений.
