# LARP Studio / мастерская «Без правил»: передача проекта

Дата комплекта: 12 ноября 2026 года. Версия программы: 0.5.1, Android versionCode 6.
Снимок репозитория: 421ed0636c9aa65518aeb088480bc565577a101e. Ветка main, все 213 отслеживаемых файлов включены.

Для Клода сначала откройте 00_Контекст_для_Claude.md и 00_Задача_для_Claude.md.
Весь код находится в 01_Source. Исходное пользовательское ТЗ и PDF — 02_Originals.
Уточнения последних обсуждений находятся в 00_Последние_требования.md; они имеют
приоритет над прежними планами, но ещё не реализованные предложения помечены явно.

Состав:
- 01_Source — полный текущий код: браузерная мастерская, Flutter Android/iOS,
  прежняя Python/PySide6 мастерская, схемы/миграции/политики/тесты базы,
  тесты, зависимости, сценарии сборки и GitHub Actions, SPEC/CHANGELOG/TESTING и docs.
- 02_Originals — исходное ТЗ, PDF карточек, используемый логотип, шаблон и QR.
- 03_History — вся история ветки main в переносимом Git bundle и текстовый список коммитов.
- 04_Verification — сохранённые логи/скриншоты проверок; полный отчёт в 01_Source/TESTING.md.
- 00_Карта_базы.md — карта таблиц, прав, RPC и файлов SQL.
- 00_Данные_облака.md — что отсутствует в комплекте и как получить настоящую копию данных.
- CONTENTS.json и SHA256SUMS.txt — опись и контрольные суммы файлов данного варианта архива.

В полном архиве дополнительно:
- 05_Builds/Android — все четыре подписанных APK версии 0.5.1 и их SHA256.
- 05_Builds/Web — сохранённая сборка браузерного сайта. Для запуска нужен HTTP-сервер
  и действующий Supabase; это не автономная Windows-мастерская.
- 06_Test_examples — демонстрационные пакеты и примеры экспорта из тестов.

ВАЖНО: это комплект разработки, а не полный дамп работающей облачной базы.
Настоящие строки проектов/аккаунтов/участников и все загруженные в Supabase видео
в этом комплекте отсутствуют. SQL-файлы описывают структуру и правила, а не содержимое.
Проект Supabase на последнем скриншоте владельца приостановлен, данные помечены сохранёнными.

Пароли, приватный Android-ключ подписи, его резервная копия, service-role ключи,
сеансы авторизации, тестовые .env, кеши, SDK и сырые дампы устройств не включены.
Публичные config.json включены намеренно: Publishable key допустим в приложении,
он не заменяет административный доступ и не позволяет выгрузить закрытую базу.
Приватный ключ подписи нужен разработчику отдельно для выпуска Android-обновлений
поверх установленных APK, но его нельзя отправлять в общий контекст для ИИ.

Отдельного современного Windows EXE с локальным хранением и синхронизацией пока нет.
Старый Python desktop-код сохранён, но не обладает всеми возможностями текущей веб-мастерской.
Полноценный браузерный игрок/PWA для iPhone пока не создан. iOS-проект — исходная заготовка.
