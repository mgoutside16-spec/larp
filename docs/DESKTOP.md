# LARP Studio

Локальная мастерская для подготовки ролевых игр живого действия. Первая версия
создаёт проекты, записи с текстом/фото/аудио/видео, постоянные пятизначные коды,
локации, списки Excel, карточки PDF и переносимые игровые пакеты `.rpgpack`.
Интернет при работе с игровыми материалами не нужен.

Основное техническое задание — [SPEC.md](SPEC.md). Реализуются этапы 1–2.
Мобильный клиент и сервер обновлений пока не разработаны.

## Запуск на Windows из исходников

Установите Python 3.12 (64-bit). В PowerShell в папке репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pip install --no-deps -e .
.\.venv\Scripts\python -m larp_studio
```

Для обычного запуска нужны зависимости из `requirements.txt`; dev-набор добавляет
тесты и сборщик. На Windows используется системный мультимедийный backend Qt;
для обмена рекомендуется MP4 с H.264/AAC, MP3/WAV, PNG/JPEG. Доступность конкретных
кодеков нужно проверить на целевом компьютере. Проект сохраняет исходные файлы,
перекодирование не выполняется.

## Работа мастерской

1. «Создать проект»: введите название игры и выберите родительскую папку.
   Программа создаст внутри новую папку игры. Существующие папки не заменяются.
2. В разделе «Локации» добавьте места на полигоне.
3. Нажмите «Новая запись», задайте название и локацию, добавьте блоки.
   Файлы можно выбрать или перетащить в окно редактора. Кнопки «Выше»/«Ниже»
   меняют порядок. Текст поддерживает абзацы, заголовки, жирный и курсивный шрифт.
4. «Предпросмотр игрока» показывает блоки в заданном порядке и открывает медиа
   внутри приложения. «Сохранить запись» закрепляет автоматически выданный код.
5. Поиск работает по названию, коду и локации; таблица сортируется по заголовкам.
   Выделите запись для копирования кода, просмотра, редактирования или удаления.
6. «Экспорт для печати» создаёт XLSX или PDF (8 карточек A4). Название и локация
   скрыты на PDF по умолчанию, их можно включить отдельно.
7. «Сборки и версии» создаёт `.rpgpack`, проверяет целостность и импортирует пакет
   в новую папку проекта. Импорт не заменяет существующую игру.

Изменения записи сохраняются **по кнопке сохранения**. «Отмена» оставляет запись
без изменений. Последний проект можно открывать автоматически через «Настройки».
Для резервной копии используйте «Создать копию проекта»: новая игра получает
свой UUID, содержание и коды сохраняются. Коды удалённых записей не выдаются заново.

В папке игры находятся `project.sqlite3` и `media/`. Медиа копируются в проект;
исходные файлы можно перемещать. Не удаляйте `media/` вручную. Добавленный в
редактор файл может остаться в хранилище после отмены — это безопасный запас;
в `.rpgpack` попадают только используемые материалы. Сначала закрывайте программу,
если переносите папку проекта вручную. Содержимое локальных пакетов не шифруется.

## Проверки

```powershell
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python -m larp_studio --smoke-test
```

Тесты автоматически используют Qt offscreen; видимое окно не требуется.
Фактические результаты и непроверенные сценарии — [TESTING.md](TESTING.md).

## Сборка Windows-приложения

На Windows, после установки dev-зависимостей:

```powershell
.\.venv\Scripts\python -m PyInstaller --noconfirm LARPStudio.spec
```

Результат: `dist\LARP Studio\LARP Studio.exe` и соседние файлы. Для передачи
другому компьютеру упакуйте **всю папку** `dist\LARP Studio`, а не только EXE.
Это переносимая сборка без подписи и установщика. `LARPStudio.spec` включает
шрифт для кириллицы в PDF вместе с лицензией. Linux не может собрать Windows EXE.
GitHub Actions содержит Windows-сборку и проверку запуска; workflow выполнится
после отправки репозитория на GitHub. Результат CI в этой сессии не подтверждён.

## Облачная среда

```bash
/workspace/.venvs/larp-studio/bin/python -m pytest -q
QT_QPA_PLATFORM=offscreen LARP_STUDIO_CONFIG_DIR=/workspace/.larp-studio \
  /workspace/.venvs/larp-studio/bin/python -m larp_studio --smoke-test
```

Для обычной Linux-машины:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m larp_studio
```

Нужны системные библиотеки Qt (EGL/OpenGL, XKB) и графическая сессия для видимого
окна. В облаке GUI проверяется без дисплея; браузерного интерфейса нет.
`LARP_STUDIO_CONFIG_DIR` при необходимости задаёт папку настроек вместо системной.

Архитектура: `src/larp_studio/project.py` — транзакции, коды, медиа;
`packages.py` — формат и импорт; `exports.py` — печать; `ui/` — PySide6.
Контракт пакетов описан в [docs/RPGPACK.md](docs/RPGPACK.md).
