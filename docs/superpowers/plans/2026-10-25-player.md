# Player Android Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Independent domains may use dispatching-parallel-agents.

**Goal:** Рабочий устанавливаемый Android APK по ТЗ с автономными материалами и двумя способами обновления.
**Architecture:** Flutter, SQLite с отдельным состоянием игрока, атомарные каталоги версий, совместимый .rpgpack. Supabase публикует приватные неизменяемые снимки, доступные игроку по известному UUID.
**Tech Stack:** Flutter stable, Dart, SQLite, archive/crypto, локальные image/audio/video, Supabase REST/Storage.
**Spec:** docs/superpowers/specs/2026-10-25-player-design.md и SPEC.md.

## Global Constraints

- Android APK без Google Play. Русский тёмный интерфейс. Без авторизации игроков.
- 3 неправильные попытки подряд → 30 минут, состояние сохраняется, история доступна.
- Весь игровой контент работает без сети. Внешние проигрыватели не используются.
- Импорт/обновление атомарны; UUID/версия/неизменяемые коды/SHA256 обязательны.
- Мастерская, облачные проекты и прежняя локальная база сохраняются.
- Онлайн-публикация и ручной импорт обязательны. iOS signing не доступен в Linux.

## Review Focus

- ZIP с ложными размерами, повторными именами и обходом пути не повреждает файлы.
- Процесс завершается между записью файлов и переключением SQLite.
- Параллельные вводы/импорты/скачивания не обходят блокировку и CAS.
- Обновление с удалённой записью не показывает другой секретный материал из истории.
- Публикация старой версии/чужого объекта не раскрывает мастерские данные.
