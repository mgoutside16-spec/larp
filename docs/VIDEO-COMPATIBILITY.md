# Совместимость видео в «Мире Снов для Граней»

## Принцип

Windows-мастерская **всегда** конвертирует добавляемое видео через FFmpeg для телефонов.
Переключатель сжатия касается только фотографий и аудио. Исходный видеофайл не
добавляется в игру при ошибке FFmpeg и не заменяет результат, даже если готовый
MP4 оказался больше исходного файла.

Профиль: MP4 + H.264 Baseline Level 3.1, 8-bit yuv420p, до 1280×720
(вертикально — до 720×1280), максимум 30 FPS, AAC-LC 44,1 кГц, faststart.
Разрешение кадров сохраняет пропорции; размер итогового MP4 может увеличиться.

## Уже загруженные видео

Исправление программы **не меняет существующие медиа само по себе**.
После установки новой Windows-мастерской:

1. Откройте игру, содержащую проблемные записи, например код **24980**.
2. Создайте резервную копию .rpgpack перед массовой обработкой.
3. Перейдите в «Сборки и версии» и нажмите «Подготовить видео и медиа».
4. Дождитесь окончания обработки всех материалов и проверьте записи.
5. Нажмите «Опубликовать для игроков» и дождитесь подтверждения публикации.
6. Игрокам достаточно дождаться обновления игры при доступе к интернету;
   удалять или переустанавливать APK не нужно.

Для офлайн-игроков можно экспортировать свежий .rpgpack и передать его вручную.

## Проверки

- `node --test desktop/tests/transcode.test.cjs` — FFmpeg smoke-тесты.
- `cd web && npm test && npm run build` — регрессии мастерской.

Android 10 (vivo Y20s) следует проверять на реальном телефоне после
публикации: автоматическая проверка кодирования не заменяет аппаратное
тестирование воспроизведения.
